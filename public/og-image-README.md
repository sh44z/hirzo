# OG Image Placeholder

Place a 1200×630 PNG at `public/og-image.png`.

This image is used as the OpenGraph and Twitter card image for Hirzo.

Recommended content:
- Hirzo logo centred or top-left
- Tagline: "Entry-Level Sales Jobs UK"
- Brand background colour: `#4f46e5` (indigo)
- White text, clean layout

Tools to generate it:
- [og-image.vercel.app](https://og-image.vercel.app)
- Figma / Canva export at exactly 1200×630
- Next.js `ImageResponse` via an `/api/og` route
